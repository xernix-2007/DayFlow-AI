# DayFlow Flutter app

## Run

From this directory:

```bash
flutter pub get
flutter run
```

## Platforms

The project is intended to target Android and Windows first. iOS, macOS, Linux and web can be enabled later as platform requirements are finalized.

## Current milestone

The repository contains the initial Today screen plus task/session models, SQLite schema, focus timer service and local reminder service. The next integration step is wiring these services into Riverpod state and the UI.
